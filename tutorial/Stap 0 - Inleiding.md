## Wat ga je bouwen in deze tutorial?
De tutorial bestaat uit 8 stappen. Het doel van de tutorial is als volgt:
- De code wordt opgesplitst in meerdere bestanden.
- Je gaat werken met een echte Todo-klasse in plaats van losse Map-gegevens.
- Je maakt een service die alle data-handelingen uitvoert.
- Je voegt een dialoog toe om nieuwe taken te maken.
- Daarna vervang je de lokale lijst door Firebase Firestore, zodat taken bewaard blijven.
